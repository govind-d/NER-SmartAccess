# NER-SmartLogix-AI — REST API & WebSocket Contract (Phase 1)

Base URL: `http://localhost:8080/api/v1`
Auth: `Authorization: Bearer <accessToken>` on every endpoint except `/auth/**`, `/actuator/health`, `/swagger-ui/**`.
Interactive docs (generated by springdoc): `http://localhost:8080/swagger-ui.html`

---

## 0. Conventions

**Success envelope**

```json
{
  "success": true,
  "message": "Road status updated",
  "data": { "...": "..." },
  "timestamp": "2026-08-28T10:15:30+05:30"
}
```

**Error envelope** (produced by `GlobalExceptionHandler`)

```json
{
  "success": false,
  "message": "Validation failed",
  "path": "/api/v1/incidents",
  "status": 400,
  "errors": [
    { "field": "severity", "message": "must not be null" }
  ],
  "timestamp": "2026-08-28T10:15:30+05:30"
}
```

**Status codes:** 200 OK · 201 Created · 204 No Content · 400 validation · 401 missing/expired token · 403 wrong role · 404 not found · 409 business conflict · 422 rule violation · 500 unexpected.

**Paging:** `?page=0&size=20&sort=createdAt,desc` → Spring `Page<T>` serialized as `{content, page, size, totalElements, totalPages}`.

## 14. WebSocket / STOMP Contract

**Handshake:** `ws://localhost:8080/ws` (SockJS fallback). Send the JWT in the STOMP `CONNECT` header: `Authorization: Bearer <token>` — validated by a `ChannelInterceptor`.

| Direction | Destination | Payload | Who receives it |
|---|---|---|---|
| server → client | `/topic/vehicles` | `VehicleLocationDto` | dashboard subscribers |
| server → client | `/topic/vehicles/{id}` | `VehicleLocationDto` | tracking page |
| server → client | `/topic/incidents` | `IncidentDto` | all map clients |
| server → client | `/topic/alerts` | `AlertDto` | all clients |
| server → client | `/topic/alerts/district/{code}` | `AlertDto` | district-scoped clients |
| server → client | `/topic/roads/status` | `RoadStatusChangeDto` | all map clients |
| server → client | `/topic/deliveries/{id}` | `DeliveryStatusDto` | manager + driver |
| server → client | `/user/queue/notifications` | `NotificationDto` | one user |
| client → server | `/app/gps` | `GpsPingRequest` | driver app pushes position |
| client → server | `/app/subscribe-district` | `{districtCode}` | scoping request |

```json
// /topic/vehicles
{ "vehicleId": 7, "vehicleNumber": "ML01AB1234", "latitude": 25.5788,
  "longitude": 91.8933, "speedKmph": 34.2, "heading": 118.0,
  "deliveryId": 55, "deliveryStatus": "IN_TRANSIT",
  "recordedAt": "2026-08-28T10:15:30+05:30" }
```
